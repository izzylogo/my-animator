# Tool checklist

Compiled from public docs and tool lists for Adobe Animate, Toon Boom Harmony, Moho,
OpenToonz, Krita, TVPaint and Clip Studio Paint (ideas only; no code or assets copied).

✅ = in the app · 🔜 = planned, with the phase it belongs to · ➖ = left out on purpose

## Selecting and moving
| Tool | Status |
|---|---|
| Move / Free transform (move, resize, rotate, flip) | ✅ |
| Squash and stretch (Shift while resizing, keeps volume) | ✅ |
| Rectangle select, Freehand lasso | ✅ |
| Select all, deselect, copy / cut / paste a selection | ✅ |
| Reshape / Magnet (bend vector lines) | ✅ |
| Polygonal lasso, ellipse select, magic-wand select | 🔜 next tools round |
| Bend points: add points on a line, drag to bend, curve handles, sharp or smooth | ✅ |
| Envelope / Perspective deform | 🔜 Phase 5 |
| Pump (thicken a line locally), Width tool | 🔜 Phase 5 |
